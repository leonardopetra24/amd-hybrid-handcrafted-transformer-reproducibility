# Code and Data Availability template

A reproducibility package containing executable preprocessing and feature-extraction code, anonymized sample and source identifiers, harmonized labels, duplicate-screening records, final ROI identifiers and SHA-256 provenance records, immutable image-level fold assignments, model configurations, random seeds, software dependencies, prediction files, statistical analyses, and table/figure regeneration resources is publicly available at **[PUBLIC_GITHUB_URL]**. Original fundus photographs are not redistributed where restricted by source-repository licenses; users should obtain them from the original repositories. The historical operator-selected ROI coordinates were not retained, and exact pixel-level replay of the original assisted ROI placement is therefore not claimed. Third-party gated model weights are not redistributed and are referenced using their exact upstream identifiers.
